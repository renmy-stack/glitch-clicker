# グリッチ・クリッカー

拾った古いゲーム機「GLITCH BOY」に入っていた、バグまみれのレトロRPGを遊ぶ放置・クリッカー。
タップで敵を倒し、仲間を雇って放置。おかしな操作で「裏技（バグ）」を見つけ、
魔王を倒すと「デバッグメニュー（公式チート）」が開く。
iPhone の Safari で遊ぶ Web アプリ（PWA）。

## 遊び方
1. 画面（またはゲーム機の A ボタン）をタップして敵を叩く
2. ゴールドで **仲間** を雇うと勝手に戦う（放置OK。閉じている間も8時間ぶんまで稼ぐ）
3. 10匹倒すと次のエリア。10エリアごとにボス。エリア60の魔王を倒すとエンディング
4. **裏技** タブ（章立ての攻略本、330個）のヒントを頼りに、へんな操作でバグを見つける → メモリ片。★2〜3の一部は見つけると常時効果（DPS・ゴールド・かいしん率・クールタイム・放置上限・レア率）が付く。ヒントは章ごとに3つずつ開き、◆1で買える。毎日「きょうの うわさ」で1つ
5. エンディング後、**デバッグ** タブでメモリ片を使って公式チートを買う
6. 「カセットを差し直す」で周回。全ダメージ ×4/周。2周目から新しいバグが出る

1周目の要素: スキル3種（エリア3・8・15で解放、クールタイム制）、仲間の「きわめ」（10・25・50・100・200人で DPS ×2）、ボス撃破ごとの ごほうび3択、レア敵（ミミック・バグった敵）、ゾーン導入文

## ファイル
- `index.html` / `style.css` … 画面（ゲーム機の枠・タブ・パネル）
- `data.js` … ゾーン・敵・仲間・スキル・チート・実績の定義（数値調整はここ）
- `bugs.js` … 裏技330個の定義（章・ヒント・★・イベント・判定・常時効果）。追加は `add(章, id, 名前, ヒント, ★, イベント, 判定)` 1行
- `game.js` … ゲーム本体（状態・戦闘・裏技検出・チート・周回・描画・セーブ）
- `music.js` … 8bit風 BGM（WebAudio のステップシーケンサー。曲はタイトル・草原/森・洞窟/山・城/魔王城・ボスの5曲。音源ファイルなし）
- `sw.js` / `manifest.webmanifest` … PWA
- `assets/enemy/*.png` `assets/ally/*.png` `assets/bg/*.jpg` `assets/icon.png` … 画像（ChatGPT 生成）

## 開発
```
python -m http.server 8091
```
で http://127.0.0.1:8091/?debug を開くと、コンソールで `ff(秒)`（早送り）、`tapN(回数)`、`S`（状態）が使える。
セーブは localStorage（キー `glitch-clicker-save`）。

実機での開発用: URL に `?dev` を付けると 設定タブに「⏩ はやおくり ×1000」「1じかん すすめる」「8じかん すすめる」が出る（公開URL でも可: `https://renmy-stack.github.io/glitch-clicker/?dev`）。使うとその周は「改造」扱い。
